# RealRDEA Project Blueprint Studio

A free, browser-side tool that organizes a project brief into a product blueprint, design-system outline, and build sequence. It makes no AI calls and needs no API key.

## Source archive

Download [realrdea-blueprint-studio-source.tar.gz](./realrdea-blueprint-studio-source.tar.gz) to get the current app source and MIT license.

## Important

This is the source for a ZiteJS app. It imports Zite's shared UI components and is not a standalone Vite app without those platform dependencies. The generator formats the user's brief; it does not create finished software, call an AI model, or promise the limits of any AI provider.

The hosted app needs an internet connection. Once loaded, blueprint text is assembled in the browser and is only sent elsewhere if the visitor chooses to copy or download it.
